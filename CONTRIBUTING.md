# Contributing

Read AGENTS.md, docs/AGENT-GUIDE.md and the sourcing guide. Use Node.js 24,
run npm ci --ignore-scripts and npm run check, update affected docs and obtain
independent review. Keep upstream blobs unchanged and retain source licenses.
Use Conventional Commits. The initial authorized delivery is direct to main;
ordinary later changes follow the branch/PR default unless explicitly directed.
No release follows automatically from a push.
